# 전시회 사진·영상 자동 편집 도구

전시회 사진 수백 장과 영상 클립을 **폴더에 넣기만 하면** 전환효과·Ken Burns 모션·
한글 자막·배경음·효과음이 들어간 완성 영상 1편을 뽑아 주는 도구입니다.

---

## 1. 핵심 요약

| 항목 | 내용 |
|---|---|
| 입력 | `media/photos`(사진), `media/videos`(영상), `captions.csv`(자막·선택) |
| 출력 | `out/exhibition.mp4` — 1920×1080 / 30fps / H.264 + AAC |
| 처리 방식 | ffmpeg 필터그래프를 파이썬이 조립해 실행 (클라우드 업로드 없음, 전부 내 컴퓨터에서) |
| 사진 1장당 | 기본 3.6초 + 0.7초 전환, 줌·팬 모션 8종을 번갈아 적용 |
| 자막 | libass 기반 — 볼드·외곽선·슬라이드 인·키워드 강조색 |
| 소리 | 배경음 + 전환 효과음(휘익)·임팩트·반짝임 자동 배치, 음량 -14 LUFS 정규화 |
| 규모 | 사진 수백 장 대응 (계층 병합 방식으로 필터그래프 과부하 회피) |

## 2. 단계별 실행 방법

### 2-1. 설치 (처음 한 번만)

```bash
cd tools/exhibition-video
./setup.sh
```

`setup.sh`가 하는 일 — 가상환경 `.venv` 생성 → 의존성 설치 → ffmpeg·한글폰트 확인.
프로젝트 본체(Node.js)와 완전히 분리된 폴더/가상환경이라 **의존성 충돌이 없습니다.**

한글 폰트가 없다는 안내가 나오면:

| OS | 명령 |
|---|---|
| Ubuntu / Debian | `sudo apt-get install -y fonts-nanum fonts-noto-cjk` |
| macOS | 추가 설치 불필요 (AppleSDGothicNeo 자동 사용) |
| Windows | 추가 설치 불필요 (맑은 고딕 자동 사용) |

### 2-2. 소재 넣기

```
tools/exhibition-video/
├── media/
│   ├── photos/     ← 전시 사진 (.jpg .png .webp .heic …)
│   ├── videos/     ← 영상 클립 (.mp4 .mov .avi …)
│   └── audio/      ← bgm.mp3 (없으면 저작권 안전한 기본 음악 자동 생성)
```

순서는 `config.json`의 `input.order`로 정합니다.

| 값 | 정렬 기준 |
|---|---|
| `"name"` | 파일명 자연 정렬 (IMG_2 → IMG_10 순서 보장) — **기본값** |
| `"shot"` | EXIF 촬영일시 순 (없는 파일은 파일명 순) |
| `"mtime"` | 파일 수정일 순 |

### 2-3. 자막 적기 (선택, `captions.csv`)

```csv
filename,title,caption,emphasis
art_001.jpg,빛의 결 No.1,캔버스에 아크릴 · 116.8 x 91.0 cm,빛의 결
IMG_2043.jpg,여백의 시간,캔버스에 유채 · 90.9 x 72.7 cm,여백
```

| 열 | 설명 |
|---|---|
| `filename` | 파일명(확장자 포함). 파일명 일부만 적어도 유일하게 매칭되면 인식 |
| `title` | 굵은 큰 줄 (작품명) |
| `caption` | 작은 줄 (재료·크기·설명) |
| `emphasis` | 강조색+볼드로 표시할 단어. 여러 개는 `\|`로 구분 |

> 작품명·재료·치수는 **적은 그대로** 화면에 나갑니다. 도구가 임의로 줄이거나 바꾸지 않습니다.

### 2-4. 시험 렌더 → 최종 렌더

```bash
source .venv/bin/activate

python3 build_video.py --preview --limit 12   # ① 앞 12장만 720p로 빠르게 확인
python3 build_video.py --preview              # ② 전체를 720p로 확인
python3 build_video.py                        # ③ 최종 1080p 렌더
```

| 옵션 | 용도 |
|---|---|
| `--preview` | 1280×720 · 빠른 프리셋 → `out/preview.mp4` |
| `--limit N` | 앞에서 N개만 사용 (구성 확인용) |
| `--config 파일` | 다른 설정 파일 사용 (세로형 숏폼용 설정 등) |
| `--out 경로` | 출력 파일명 지정 |

## 3. 설정 파일 (`config.json`) 바로 쓰는 예시

### 3-1. 자주 바꾸는 값

| 키 | 기본값 | 의미 |
|---|---|---|
| `timing.still_duration` | `3.6` | 사진 1장이 머무는 시간(초) |
| `timing.transition` | `0.7` | 전환 길이(초) |
| `timing.video_max` | `8.0` | 영상 클립 1개당 최대 사용 길이(초) |
| `style.grade` | `"gallery"` | 색보정 — `neutral` `warm` `cool` `gallery` `cinema` |
| `style.accent` | `"#FFD24A"` | 강조색 (자막 키워드·부제) |
| `style.zoom` | `1.16` | Ken Burns 줌 강도 (1.0 = 정지) |
| `style.grain` | `0` | 필름 그레인 세기 (0 = 없음, 6~12 권장) |
| `style.show_counter` | `true` | 좌상단 `03 / 120` 카운터 표시 |
| `audio.bgm_gain_db` | `-17` | 배경음 크기 |
| `audio.sfx_gain_db` | `-7` | 효과음 크기 (`audio.sfx: false`로 끌 수 있음) |

### 3-2. 목적별 추천 프리셋

| 목적 | 바꿀 값 |
|---|---|
| 전시장 상영용 (차분) | `still_duration: 5.0`, `transition: 1.0`, `grade: "neutral"`, `sfx: false` |
| 유튜브 하이라이트 | 기본값 그대로 |
| 인스타 릴스·숏폼 (세로) | `width: 1080`, `height: 1920`, `still_duration: 2.2`, `transition: 0.4` |
| 필름 감성 | `grade: "cinema"`, `grain: 8`, `vignette: true` |

### 3-3. 구간(막) 나누기

```json
"sections": [
  { "at_index": 0,  "text": "1부 · 빛" },
  { "at_index": 40, "text": "2부 · 결" }
]
```
`at_index`는 **미디어 목록 순번(0부터)** 입니다. 해당 사진 앞에 구간 타이틀 카드가 들어갑니다.

### 3-4. 내레이션 넣기

`media/audio/narration.mp3`를 넣고 `"audio": { "narration": "media/audio/narration.mp3" }` 로 지정하면,
내레이션이 나올 때 배경음이 자동으로 눌러집니다(사이드체인 더킹).

## 4. 동작 원리 (유지보수용)

```
build_video.py                 전체 흐름 제어
└── lib/
    ├── env.py                 ffmpeg·ffprobe·한글폰트 탐색, 명령 실행
    ├── media.py               폴더 스캔 · 자연 정렬 · EXIF · captions.csv 매핑
    ├── clips.py               사진→Ken Burns 클립, 영상→규격 통일, 타이틀 카드 배경
    ├── transitions.py         xfade 전환 + 계층 병합 + 타임라인 계산
    ├── subtitles.py           ASS 자막 생성 (애니메이션·강조)
    └── audio.py               배경음·효과음 합성 및 최종 믹싱
```

각 파일이 한 가지 일만 맡으므로, 고치고 싶은 부분만 열면 됩니다.

| 바꾸고 싶은 것 | 열어야 할 파일 |
|---|---|
| 줌·팬 움직임 추가 | `lib/clips.py` → `MOTIONS`, `_kenburns()` |
| 색보정 프리셋 추가 | `lib/clips.py` → `GRADES` |
| 전환효과 종류·순서 | `lib/transitions.py` → `TRANSITION_CYCLE` (ffmpeg xfade 56종) |
| 자막 디자인·위치 | `lib/subtitles.py` → `_styles()`, `caption()` |
| 효과음 소리 자체 | `lib/audio.py` → `_whoosh()`, `_impact()`, `_shimmer()` |

### 왜 '계층 병합'인가

사진 200장을 한 번의 `filter_complex`에 넣으면 ffmpeg가 필터그래프·메모리 한계로 실패합니다.
그래서 √n개씩 묶어 중간 파일로 합치고, 그 결과를 다시 합칩니다(2단계로 끝나 화질 손실 최소).
전체 길이와 각 사진의 등장 시각은 순차 합성과 **수학적으로 동일**합니다.

```
start_i = Σd(0..i-1) − i × T        (T = 전환 길이)
총 길이 = Σd − (n−1) × T
```

자막 타이밍은 이 식으로 계산하므로, 병합 방식과 무관하게 항상 정확히 맞습니다.

## 5. 렌더 시간 (실측값)

4코어 환경에서 직접 측정한 값입니다. 사진 1장 3.6초 + 전환 0.7초 기준.

### 측정 결과

| 설정 | 투입 | 결과 영상 | 소요시간 | 항목당 |
|---|---|---|---|---|
| 720p · veryfast (`--preview`) | 205개 | 10분 04초 / 103MB | 13분 24초 | 3.9초 |
| 1080p · faster · crf 20 | 38개 | 2분 03초 / 101MB | 9분 30초 | 15.0초 |
| 1080p · medium · crf 18 (기본) | 38개 | 2분 03초 / 163MB | 17분 05초 | 27.0초 |

### 사진 장수별 예상 시간

| 사진 수 | 완성 영상 | 720p 시험 | 1080p 빠름 | 1080p 고화질 |
|---:|---:|---:|---:|---:|
| 50장 | 2.4분 | 3분 | 12분 | 22분 |
| 100장 | 4.8분 | 7분 | 25분 | 45분 |
| 200장 | 9.7분 | 13분 | 50분 | 1시간 29분 |
| 300장 | 14.5분 | 20분 | 1시간 15분 | 2시간 14분 |
| 500장 | 24.2분 | 33분 | 2시간 5분 | 3시간 44분 |

코어가 많을수록 빨라집니다(세그먼트 렌더를 코어 수만큼 동시에 돌립니다).

### 시간이 어디에 쓰이는가 (1080p 기본 설정 기준)

| 단계 | 비중 |
|---|---:|
| 세그먼트 렌더 (줌·팬·색보정) | 29% |
| 전환 병합 1단계 | 27% |
| 전환 병합 2단계 | 23% |
| 자막·최종 합성 | 20% |
| 오디오 합성 | 1% |

재인코딩이 3번(병합 2회 + 최종 1회) 일어나므로 전체 시간은 **완성 영상 길이의 약 8배**입니다.

### 빠르게 하는 법

| 방법 | `config.json` | 효과 |
|---|---|---|
| 시험은 720p로 | `--preview` 옵션 사용 | 가장 빠름. 구성 확인용 |
| 최종 화질을 한 단계 낮추기 | `"preset": "faster", "crf": 20` | **1.8배 빠름**, 파일 크기 38% 감소 |
| 사진당 시간 줄이기 | `"still_duration": 3.0` | 영상이 짧아진 만큼 비례해 단축 |

> 실무 권장: **720p로 구성 확인 → 1080p는 자기 전에 한 번 돌려놓기**

## 6. 렌더 전 체크리스트

- [ ] `media/photos`에 사진이 들어 있고, 파일명 순서가 원하는 상영 순서와 같은가
- [ ] 세로 사진과 가로 사진이 섞여 있는가 → 가로 16:9로 잘리므로 중요한 부분이 잘리지 않는지 `--limit`로 확인
- [ ] `captions.csv`의 작품명·재료·치수가 도록(圖錄) 원문과 글자 단위로 같은가
- [ ] 배경음을 직접 넣었다면 **상업적 이용 가능한 음원**인가 (기본 합성 음원은 저작권 문제 없음)
- [ ] 관람객 얼굴이 나오는 사진은 초상권 동의를 받았는가
- [ ] `--preview`로 전체를 한 번 본 뒤 최종 렌더를 돌렸는가
- [ ] 디스크 여유 공간이 넉넉한가 (중간 파일이 최종 파일의 3~5배까지 쌓였다 지워짐)

## 7. 자주 나는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| 자막이 □□□로 깨짐 | 한글 폰트 없음 | `sudo apt-get install fonts-nanum` 후 재실행 |
| `ffmpeg를 찾지 못했습니다` | 가상환경 미활성화 | `source .venv/bin/activate` 후 재실행 |
| 사진 순서가 뒤죽박죽 | 파일명 규칙 불일치 | `input.order`를 `"shot"`(촬영순)으로 변경 |
| 렌더가 너무 오래 걸림 | 1080p·medium 프리셋 | [5. 렌더 시간](#5-렌더-시간-실측값)의 '빠르게 하는 법' 참고 |
| 자막이 안 나옴 | `captions.csv` 파일명 불일치 | 로그의 `자막 매칭 N건` 숫자 확인 |
| 소리가 너무 큼/작음 | 게인 설정 | `audio.bgm_gain_db`, `audio.sfx_gain_db` 조정 |
